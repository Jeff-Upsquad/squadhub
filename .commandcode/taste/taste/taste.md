# Taste
- Wants explanations in simple, plain terms before any building — explain what exists and the plan in non-technical language before implementing; also asks to restate bug/root-cause explanations in simple terms when the first explanation is too technical/jargon-heavy ("why it happened? tell me in simple terms"). Confidence: 0.95
- Prefers to be given concrete scope options and to confirm what should be built before implementation begins — including multiple-choice decisions before irreversible data changes (e.g., which duplicate account to keep/merge before deleting others) (responds well to multiple-choice follow-ups rather than the assistant assuming). Confidence: 0.9
- Approves plans that call out explicit scope boundaries — sections listing what is deliberately not touched (e.g., "Not touched (deliberately)") keep the work tight and are accepted as-is. Confidence: 0.7
- Communicates tersely (e.g., a single acronym like "CMPD", or a one-line feature request like "ALSO build an option to share by user type") and expects the assistant to resolve the shorthand from the codebase, workflows/ docs, and any attached UI screenshots rather than asking for clarification; when the assistant can't find the shorthand in Command Code's own docs and asks what it means, the user pushes back ("we have already used this workflow") expecting the project's workflows/ directory to be searched before giving up. Confidence: 0.95
- Terse shorthand can contain misspellings/homophones (e.g., "rooster" for "roster") — expects the assistant to infer the intended capability from context rather than asking for clarification. Confidence: 0.5
- Reports bugs in plain-language business terms with screenshots attached — describes the affected entity and symptom (e.g., "user changed email, cards not showing up") rather than the technical cause, leaving root-cause investigation to the assistant; may also name a concrete example user and a working reference case to triangulate the divergence (e.g., "scrolling behaviour not correct for other users (example chindoora) compared to admin"). Confidence: 0.7

Confidence: 0.6

Confidence: 0.6
